# 📏 Library Conventions & Standards

This document defines the naming, organization, and quality standards for every file in this library. Follow these when adding or modifying components to keep the library consistent.

---

## Folder structure

```
ad_library/
├── Schematic_Symbols/     # .SchLib files — one per component category
├── Footprints/            # .PcbLib files — one per PCB footprint category
├── 3D_Models/             # .STEP / .STL files — organized by component type
│   └── <Category>.<subcategory>/  # e.g. Capacitor_SMD.3dshapes/
├── Int_Library/           # Compiled integrated libraries
│   └── <Category>/
│       ├── <Category>.LibPkg              # Altium source project
│       └── Project Outputs for <Category>/ # Compiled .IntLib (auto-generated)
├── Script/                # Altium scripting (.PrjScr, .pas)
├── Images_asset/          # Reference images and screenshots
├── docs/                  # Process guides (you are here)
└── Layer_Stack_Details.md # KiCad → Altium layer mapping reference
```

## Schematic symbol naming (.SchLib)

### File names

| Convention | Example |
|------------|---------|
| `<Category>.SchLib` | `Regulator_Switching.SchLib` |
| `<Category>_<SubType>.SchLib` | `Amplifier_Operational.SchLib` |
| `<Manufacturer>.SchLib` (if one-vendor) | `TI.SchLib` |

**Rules:**
- Use **underscores** for word separation (not spaces).
- One file per logical category. Don't create a new `.SchLib` for a single component unless it's a new category entirely.
- Categories follow the KiCad 9.0 convention (this library was converted from KiCad).

### Component names inside the library

| Format | Example |
|--------|---------|
| `Manufacturer_MPN_Description` | `TI_TPS61023DRLR_Boost_Converter` |
| `Generic_Description` (if multi-source) | `NPN_Transistor_SOT23` |

## 3D model organization

### Folder naming

```
3D_Models/<Category>_<SubType>.<ext>shapes/
```

| Examples |
|----------|
| `3D_Models/Capacitor_SMD.3dshapes/` |
| `3D_Models/Connector_JST.3dshapes/` |
| `3D_Models/Package_SO.3dshapes/` |

### Supported formats

- **`.STEP`** — preferred. Industry standard, parametric.
- **`.STL`** — acceptable. Simpler but less editable.

### Linking path

When linking a 3D model in a footprint, use a **relative path** from the footprint file:

```
..\3D_Models\Capacitor_SMD.3dshapes\C_0805.STEP
```

This ensures the link works on any machine regardless of where the repo is cloned.

## Integrated Library organization (.IntLib)

### Folder structure per category

```
Int_Library/Regulator_DC_DC/
├── Regulator_DC_DC.LibPkg       ← Altium project (source of truth)
└── Project Outputs for Regulator_DC_DC/
    └── Regulator_DC_DC.IntLib   ← compiled library (auto-generated by Altium)
```

### When to create a new IntLib category

| Situation | Action |
|-----------|--------|
| Your component fits an existing category | Add it to that `.LibPkg`, recompile |
| Your component is a new category | Create a new `Int_Library/<NewCategory>/` folder with its own `.LibPkg` |

### Existing IntLib categories

| Category | Contents |
|----------|----------|
| `74xx` | 74-series logic |
| `Audio` | Audio amplifiers, codecs |
| `Comparator` | Voltage comparators |
| `Connectors` | All connector types |
| `Isolator` | Optocouplers, digital isolators |
| `MCU` | Microcontrollers |
| `Memory` | Flash, RAM, EEPROM |
| `Motor_Driver` | Motor controllers and drivers |
| `Passive` | Resistors, capacitors, inductors |
| `Protection` | TVS, ESD, fuses |
| `Regulator_DC_DC` | Switching regulators, LDOs |
| `RF` | RF amplifiers, transceivers |
| `Switch` | Mechanical switches, relays |
| `Transcivers` | Bus transceivers (RS485, CAN, etc.) |

## Layer stack reference

When creating footprints, use the mechanical layer assignments defined in [Layer Stack Details](../Layer_Stack_Details.md). This ensures every footprint has:
- Consistent courtyard on M6/M7
- Consistent assembly drawing on M4/M5
- Consistent 3D body on M10/M11

---

## Quality checklist (per component)

Every component must have:
- [ ] Schematic symbol with correct pin names, numbers, and electrical types
- [ ] Footprint with pads matching the datasheet (size, pitch, paste mask)
- [ ] Courtyard boundary (M6/M7) with adequate clearance
- [ ] 3D model linked (or a TODO note if not yet available)
- [ ] Added to the correct `.SchLib` / `.PcbLib` / `.LibPkg`
- [ ] Compiled and verified in Altium (no ERC errors)
- [ ] IntLib recompiled and committed
